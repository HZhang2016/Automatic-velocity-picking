# 速度谱训练数据模拟代码（MATLAB）使用说明

本目录下的 MATLAB 代码用于**正演生成深度学习训练数据**：
随机生成层状介质模型 → 合成反射波地震记录（含多次波）→ 速度分析得到速度谱 →
导出为 CSV 文件，供 `yolo_lstm/` 项目做能量团检测与多次波去除。

## 文件清单与调用关系

```
Start_createdata.m          主脚本（入口）
 ├── CreateModel.m          随机生成层状介质模型（速度/密度/厚度）
 ├── Syn_Seismogram.m       合成反射波地震记录（含多次波）
 ├── createVT.m             由平均速度生成"时间-速度对"（VT 曲线，训练标签）
 ├── Vel_Analysis.m         速度分析（双曲线扫描叠加能量 → 速度谱）
 ├── PreprocessData.m       速度谱白化预处理 + 画图检查
 └── wigb.m                 波形图绘制（自绘简化版，替代 CREWES 工具箱 wigb）
```

## 各文件功能

### 1. Start_createdata.m —— 主脚本

流程（对每个样本循环 `train_num` 次）：

1. 随机层数 `n = randi([6,10])`，调用 `CreateModel(n)` 生成模型；
2. `Syn_Seismogram(model)` 合成地震记录，返回平均速度 `T0Vav`、
   界面 T0 时间 `T`、多次波 VT 对 `Multi_Vav`；
3. `createVT(...)` 生成 201 个插值采样点的 VT 曲线（当前未写入 CSV，仅供调试用）；
4. `Vel_Analysis(synseis)` 做速度分析得到速度谱；
5. `PreprocessData(...)` 对白化后的速度谱做阈值处理（< 300000 置 0）；
6. 写出两个 CSV（见"输出数据格式"）。

**关键参数（脚本顶部）：**

| 参数 | 当前值 | 含义 |
|---|---|---|
| `train_num` | 100 | 生成样本个数 |
| `sample_num` | 2000 | 每道采样点数 |
| `interval` | 0.001 | 采样间隔（s），记录长度 2.0 s |

> 注意：`train_inputdata = zeros(1,50451)` 的预分配大小必须等于
> 速度谱元素总数（201×251=50451）。若改动速度分析参数
> （`dv`、`dt`、`vmax` 等），此处需同步修改。

### 2. CreateModel.m —— 随机介质模型

生成 `3 × N` 矩阵：第 1 行速度（m/s）、第 2 行密度（g/cm³）、第 3 行厚度（m）。

- 第 1 层固定：v = 1500 m/s，厚 150 m（模拟水层/低速层）；
- 第 2 层：v = 2500 + 10×randi([0,10])，厚 50×randi([7,9])；
- 第 3 层起：速度逐层递增 `+100×randi([4,8])`，厚度同第 2 层规则；
- 密度由 Gardner 公式计算：`ρ = 1.741 × (v/1000)^0.25`。

### 3. Syn_Seismogram.m —— 合成地震记录

- 由速度、密度计算波阻抗和**反射系数**；
- 逐层累加计算**平均速度** `Vav` 与各界面**自激自收时间** `T0`；
- 多次波：随机个数 `randi([3,N-2])-1` 个，速度恒等于第 1 层平均速度，
  T0 为 `T0(1)` 的整数倍，振幅按 `ref(1)×0.8^k` 衰减；
- 子波：60 Hz **雷克子波**，长度 400 ms；
- 观测系统：零偏移距起，道间距 5 m，共 401 道（双边放炮后取右半边 201 道）；
- 输出：`synseis`（2000×201 合成记录）、`T`、`T0Vav`（2×(N-1)，
  第 1 行平均速度、第 2 行 T0）、`Multi_Vav`（多次波 VT 对）。

### 4. Vel_Analysis.m —— 速度分析

沿双曲线时距方程 `tx = √(t0² + x²/v²)` 做扫描叠加：

| 参数 | 值 | 含义 |
|---|---|---|
| `vmin~vmax` | 0~5000 m/s | 速度扫描范围 |
| `dv` | 20 m/s | 速度间隔（251 个扫描速度） |
| `t0min~t0max` | 0~2.0 s | T0 扫描范围 |
| `dt` | 0.01 s | T0 间隔（201 个扫描时间） |
| `win_t` | 0.02 s | 时窗长度（±10 ms） |

输出转置后的 `velspectrum`（201 行 t0 × 251 列速度）：
每个（t0, v）对应时窗内沿双曲线叠加的能量平方和；单点叠加值
截断在 [0, 500] 以压制异常。

### 5. createVT.m —— VT 曲线生成

把稀疏的（平均速度, T0）对线性插值为 201 个等间隔采样点的
"时间-速度对"曲线，层间速度线性过渡、超过最后界面后取常速。

### 6. PreprocessData.m —— 白化预处理

- 画出白化前速度谱和能量直方图（检查用）；
- `ceil` 取整后将 **< 300000 的值置 0**（白化阈值），突出能量团；
- 画出白化后的速度谱和直方图。

> 注意：函数里 `reshape(data, 201, 251)` 的尺寸写死，
> 若速度分析网格改了，这里也要同步改。

### 7. wigb.m —— 波形图（自绘）

CREWES 工具箱 `wigb` 的简化替代版：逐道画归一化波形，y 轴反向。
仅用于 `Syn_Seismogram.m` 末尾的剖面显示，不影响数据。

## 输出数据格式

每生成一个样本写出两个文件（`i` 为样本号）：

### train_inputdata/`i`.csv —— 网络输入（速度谱）

- 一列共 **50451** 行 = 白化后的速度谱按**列优先**（MATLAB `(:)`）拉平；
- 还原二维谱：`reshape(data, 201, 251)`（MATLAB）或
  `data.reshape(201, 251, order='F')`（Python/numpy）；
- 坐标：行 = T0（第 1~201 行 ↔ 0~2.0 s，间隔 0.01 s），
  列 = 速度（第 1~251 列 ↔ 0~5000 m/s，间隔 20 m/s）。

### train_outputdata/`i`.csv —— 标签

- 一列共 **20** 个数：
  - 前 `2×(n-1)` 个：一次波 (平均速度, T0) 交替排列（n 为层数）；
  - 第 19 个：界面数 `n-1`；
  - 第 20 个：多次波个数；
- 多次波位置可推算：速度 = 第 1 个数（1500），T0 = 第 2 个数 × (k+1)，
  k = 1..多次波个数。

## 使用方法

```matlab
% 在 MATLAB 中切换到本目录后运行：
Start_createdata
```

- 修改样本量：改 `Start_createdata.m` 顶部的 `train_num`；
- 单样本耗时约 7~10 秒（速度分析三重循环是主要开销）；
- 运行前确保 `train_inputdata/`、`train_outputdata/` 两个文件夹已存在；
- 脚本含 `clc; clear all;`，会清空工作区。

## 已知注意事项

1. **编码**：原始文件为 GBK 编码（含中文注释），跨平台使用时建议转 UTF-8；
2. **尺寸耦合**：`Start_createdata.m` 的预分配大小、`PreprocessData.m` 的
   reshape 尺寸、`yolo_lstm/src/common.py` 中的 `H, W` 三处必须保持一致；
3. **随机性**：未固定随机种子，每次运行生成的样本不同（MATLAB 每次启动
   默认种子相同，连续两次启动运行会得到相同序列；批内样本互不相同）；
4. **配套项目**：生成的数据由 `yolo_lstm/` 项目使用，详见该目录 README.md。
